# TwinForge

Premium customizable 3D printed products hand-finished in Oman.

## Tech Stack

- Next.js 15
- React 18
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Supabase
- Lenis (smooth scroll)

## Features

- Product configurator with dropdown selections
- Phone validation (8 digits)
- Butterfly knife packing fee (+1 OMR)
- Dynamic server-side rendering
- Smooth scroll with Lenis
- Premium motion design

## Deployment

Deployed on Vercel with:
- `output: 'standalone'`
- `dynamic: 'force-dynamic'`
- `runtime: 'nodejs'`

## Database

- Supabase (PostgreSQL)
- Filament companies dropdown
- Product components with detailed pricing
- Phone validation constraints
